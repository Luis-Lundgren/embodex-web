# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability in the Embodex Web platform or Motion Exchange, please report it privately:

- **Security Contact:** Luis Lundgren
- **Email:** `lundgrenluis@gmail.com`

Please do not disclose security issues publicly until a fix has been prepared and published.

## Response Process

- We will acknowledge receipt of your report within 48 hours.
- A patched release will be deployed and published with appropriate credit.
